# 参考图拆解与产品图提示词指南

## 第 6 步执行指南：参考图拆解

用 Read 工具打开参考图（多模态识图），按以下 10 个维度输出拆解表。每个维度写一句具体描述，禁止空泛（"光线不错"❌ → "左前侧柔光，色温偏暖约 4000K，眼周无明显硬阴影"✅）：

| # | 维度 | 观察要点 |
|---|---|---|
| 1 | 景别与构图 | 特写/近景/半身；眼部在画面什么位置（居中/三分线/对角）；留白方向 |
| 2 | 机位与角度 | 平视/俯拍/仰拍；正面/3/4 侧脸/侧脸；模特视线方向（看镜头/看斜下方/闭眼） |
| 3 | 光线 | 方向（顺/逆/侧光）、软硬（柔光/硬光/环形光）、色温（暖/冷/中性）、眼内高光形状与位置 |
| 4 | 色调 | 主色调与饱和度、对比度；滤镜倾向（奶咖/冷白/胶片） |
| 5 | 模特特征 | 年龄段、脸型、眼型（圆眼/长眼/下垂眼）、瞳色深浅 |
| 6 | 妆造重点 | 眼妆风格（水光卧蚕/烟熏/纯欲粉棕/截断式）、睫毛形态、唇色、腮红位置 |
| 7 | 发型发色 | 长短发、卷直、发色（黑/棕/挑染）、碎发遮挡关系 |
| 8 | 服装与配饰 | 领口款式、颜色、耳饰项链、美甲 |
| 9 | 背景与道具 | 纯色/实景/虚化；道具（镜子/花/玻璃杯/光线装置） |
| 10 | 氛围与后期 | 整体氛围关键词 3-5 个；后期风格（胶片颗粒/清透水光/雾面奶油/高光泛白） |

拆解输出后，标注 3 个"必须保留"的核心风格要素（通常来自维度 1/3/10），它们是产品图保风格的关键。

**肖像权规则**：只提取风格要素，提示词中不描述可识别的五官特征，不生成与参考图同一个人的脸。

## 第 7 步执行指南：提示词生成

### 提示词公式

```
主体（模特+佩戴所选花色的眼部） + 妆造 + 光线 + 构图景别 + 色调氛围 + 背景 + 后期风格 + 画质词
```

美瞳产品图的差异化要求（与普通人像的区别）：

1. **眼部是绝对焦点**：虹膜纹理清晰可辨，景深向眼部聚焦
2. **花色细节精确**：必须写入 锁边颜色与粗细、内圈渐变、光泽位置（对照第 2 步产品表的花色描述）
3. **直径效果**：写入着色直径带来的放大感或自然感
4. **水光/高光质感**：泪膜反光、定轴高光的"光泽跟着眼睛跑"效果
5. **佩戴自然**：镜片贴合角膜无滑片，眼白干净，边缘无异常色环

### 中文提示词模板

```
{景别，如：半身近景偏特写}，亚洲年轻女性，{发型发色}，{妆造：如水光卧蚕纯欲眼妆、粉棕眼影、根根分明睫毛}，眼神{视线方向}，眼部为画面焦点，佩戴{花色名}美瞳：{锁边描述，如深棕细锁边}、{内圈渐变描述，如蜜糖色坚果棕渐变}、着色直径{XX}mm 自然放大双眸，{光线描述}，{色调：如奶咖暖调低饱和}，{背景}，{后期风格：如清透水光质感、轻微胶片颗粒}，皮肤纹理真实自然，商业美妆摄影质感，高清细节
```

### 英文提示词模板（ImageGen 对英文风格词更稳）

```
{shot type, e.g. half-body close-up}, young Asian woman with {hair}, {makeup: dewy aegyo-sal pure-sultry eye makeup, pink-brown eyeshadow, defined lashes}, gazing {direction}, eyes as the focal point wearing "{color name}" colored contact lenses: {limbal ring desc, e.g. fine deep-brown ring}, {inner gradient desc, e.g. honey-glazed walnut brown gradient}, {XX}mm tinted diameter with natural enlargement, {lighting}, {color palette: warm creamy low-saturation tones}, {background}, {post style: dewy clear skin, subtle film grain}, natural skin texture, commercial beauty photography, high detail
```

### 图生图提示词模板（参考图作为 image1 时）

```
参考这张图的构图、光线、色调和氛围，将画面调整为佩戴{花色名}美瞳的产品图：{锁边与渐变描述}，着色直径{XX}mm，眼妆改为{热点相关妆造}，保持{第 6 步标注的 3 个必须保留要素}，眼部为焦点，花色纹理清晰，整体氛围贴合"{热点关键词}"。
```

### 花色描述速记（常见款，生成前对照第 2 步产品表确认）

- 胡桃棕：蜜糖裹坚果的暖棕渐变，深棕锁边，水光感强
- 亚麻蓝：低饱和雾感亚麻蓝，外圈淡蓝锁边+内圈灰蓝渐变，玻璃珠感
- 野浆果：深灰锁边裹树莓粉内圈，像打了水光腮红
- 冷泡乌龙茶：金棕渐变+细腻锁边，清冷茶棕
- 松林木屋：冷棕调小直径，妈生自然感

## 第 8 步执行指南：产品图生成

### 工具调用

1. 先用 ToolSearch 加载 `ImageGen` 工具，再用 DeferExecuteTool 调用
2. 生成前告知用户：每张图约消耗 5-10 credits，确认生成数量（默认 2-4 张变体）

### 参数建议

| 场景 | 用法 |
|---|---|
| 参考图构图氛围完美，只需换花色 | 图生图：`image1`=参考图路径，`input_fidelity` 0.4-0.6（保风格但允许改花色妆造），提示词用图生图模板 |
| 参考图仅为风格灵感/有肖像权顾虑 | 纯文生图：只用第 7 步完整提示词 |
| 尺寸 | 小红书 3:4 竖图 → `1024x1536`；横版场景图 → `1536x1024` |
| quality | high（产品图需要虹膜细节） |
| 变体策略 | 同一提示词微调：① 换视线方向 ② 换景别（特写↔近景）③ 换光线氛围，各生成一张 |

### 生成后自检清单（逐张过，不合格重新生成）

- [ ] 花色与所选产品一致（对照产品表：锁边颜色、渐变、整体色调）
- [ ] 双眼对称，瞳孔位置自然，花色未溢出虹膜边界
- [ ] 眼部无畸形：无多余睫毛、眼睑无破绽、眼神不呆滞
- [ ] 水光/光泽感在线（热点若强调水光，必须明显）
- [ ] 妆造、色调、氛围贴合第 1 步热点关键词
- [ ] 无人脸与参考图明显同源（肖像权）

### 交付

- 用 present_files 展示全部产品图
- 对话中说明每张图的差异点（景别/光线/氛围），方便用户选图发布
- 提醒用户：若发布平台要求，AI 生成图需按平台规则标注
