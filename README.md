# moody-xhs-hot-content

> WorkBuddy Skill：moody 美瞳小红书热点内容一体化创作。输入【产品名 + 热点信息 + 一张参考图】，产出可直接发布的小红书种草内容包。

## 功能一览

| 步骤 | 产出 |
|---|---|
| 1. 热点搜索与整理 | 热点清单表（关键词/热度表现/美瞳结合点/情绪词） |
| 2. moody 在售产品库汇总 | 产品表格（系列/花色/直径/材质/含水量/周期/联名，≥15 个花色） |
| 3. 热点-产品匹配分析 | 四维打分（色调/直径/材质场景/联名热度）→ Top1 选品 + 推荐理由 |
| 4. 选题生成 | 3 个候选，≤20 字、情绪化表达 + emoji |
| 5. 小红书正文创作 | ≤300 字爆款结构模板 + 三类医疗器械合规尾注 |
| 6. 参考图拆解 | 10 维拆解表（景别/光线/色调/妆造/氛围…）+ 3 个必保留要素 |
| 7. 产品图提示词 | 中英双语提示词（植入花色锁边/渐变/水光细节） |
| 8. 产品图生成 | ImageGen 文生图 / 图生图（参考图风格迁移），2-4 张变体 + 自检 |

## 安装

**方式一：git clone 到用户技能目录**（所有项目可用）

```bash
git clone https://github.com/kt5s4hkhy5-oss/moody-xhs-hot-content.git ~/.workbuddy/skills/moody-xhs-hot-content
```

**方式二：下载 zip 解压**到 `~/.workbuddy/skills/` 目录
（Windows 完整路径：`C:\Users\<用户名>\.workbuddy\skills\moody-xhs-hot-content\`；项目级则放在 `<项目根>/.workbuddy/skills/`）

安装后无需其他配置，新会话中给出热点+参考图即自动触发，或明确点名「用 moody-xhs-hot-content」。

## 合规说明（重要）

美瞳属于**第三类医疗器械**，本 skill 内置以下红线：

- 文案必须保留合规尾注（"请仔细阅读产品说明书或在医务人员的指导下购买和使用…"）
- 广审批文号必须与所选产品真实对应，查不到时向使用者索要，禁止编造
- 禁用医疗功效宣称（治疗/矫正）与绝对化用语（最/第一/永久）
- 参考图只拆解风格要素，不生成可识别的真人肖像

## 数据说明

品牌与产品信息来自公开渠道（官方旗舰店、品牌官方社媒、授权电商）搜索整理，产品线随时间迭代，skill 每次运行都会重新搜索更新产品库，仓库内的基线知识仅作背景参考。
